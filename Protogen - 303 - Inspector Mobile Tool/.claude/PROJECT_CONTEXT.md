# Project Context - P303 Inspector Mobile Tool

## Product Intent
Build a mobile-first inspection experience for manufacturing floor quality checks.

## Non-Negotiables
- One-handed friendly interactions
- Large tap targets
- Fast scan-and-complete workflow
- Clear status controls: Pass, Fail, Flag
- Validation rules:
  - Fail requires note and at least one photo
  - Flag requires note

## UX Direction
Industrial and tool-like visual language with high contrast for bright factory-floor conditions.

## Core Flows
1. New inspection setup (line + unit ID)
2. Complete categorized checklist
3. Add issue details for Fail/Flag items
4. Review and submit
5. Check recent inspections and flagged follow-ups
